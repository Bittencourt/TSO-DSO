<objective>
Build the per-node `AGR-OPT` aggregator subproblem (thesis eq. 3.46): a house-separable QP
that reuses the exact Phase-3 device/aggregator `contribute!` builders, introduces the single
coupling variable `pag_j[t]` (the aggregator net active injection), and is BUILT ONCE with a
fixed quadratic ρ-penalty so each ADMM iteration only updates a scalar objective coefficient
(no JuMP rebuild).

Purpose: ADMM-01 requires the split to reuse the same builders as the centralized solve;
ADMM-03 requires build-once/re-solve. AGR-OPT is block 1 of the 2-block ADMM — orchestration,
not model re-implementation (RESEARCH Pattern 4). Getting the coupling-variable + coefficient-
update design right here (and NOT modeling λ as a Parameter) is what keeps Clarabel convex.

Output: `src/admm/AgrOpt.jl` (`AgrOpt`, `build_agr_opt`, `solve_agr!`), `test/test_agr.jl`.
</objective>
