<objective>
Build the whole-network `DSO-OPT` subproblem (thesis eq. 3.47): a SOCP that reuses
`ConvexBranchFlow.contribute!` verbatim, keeps the priced free-sign frontier export (the
SOC-exactness enabler), closes each load-node balance with an explicit coupling variable
`pag_dso_j[j,t]`, and is BUILT ONCE with a fixed quadratic ρ-penalty so each ADMM iteration
only updates scalar objective coefficients (no JuMP rebuild). The PF-04 exactness gate runs on
the CONVERGED solve so ADMM prices are trusted only when the cone is tight.

Purpose: DSO-OPT is block 2 of the 2-block ADMM. It must reuse the validated LinDistFlow
exactness copy (RESEARCH "Don't Hand-Roll") and retain the free-sign priced frontier so the
cone stays exact under reverse flow (RESEARCH Pitfall 3). Introducing the single coupling
variable per (node,hour) is what makes the coefficient update a one-call mutation (ADMM-03).

Output: `src/admm/DsoOpt.jl` (`DsoOpt`, `build_dso_opt`, `solve_dso!`), `test/test_dso.jl`.
