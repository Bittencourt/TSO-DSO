**Design decisions locked for the executor:**
- V1G does NOT create a `p_dch` variable at all; V2G (`v2g = true` constructor kwarg) does
  (research OQ1 RECOMMENDED, pre-authorized). Vars NamedTuple: `(; p_ch, soc, soc0)` (V1G) /
  `(; p_ch, p_dch, soc, soc0)` (V2G) — keeps the `:soc0` stash-key walks working (A9) and is
  handled by 43-01's trait routing in both shapes (A2).
- Session windows SUPPORT WRAP: `in_window(t)` is true for `t_arr ≤ t ≤ t_dep` when
  `t_arr ≤ t_dep`, else the union `t ≥ t_arr ∪ t ≤ t_dep` (overnight session across the horizon
  edge is still pure bounds — binary-free). Constructor guards: `1 ≤ t_arr ≤ T`, `1 ≤ t_dep ≤ T`,
  `t_arr ≠ t_dep`; contribute! re-guards against the actual `T` (Deferrable.jl:211-219 idiom).
- `soc_terminal::Union{Nothing,Real,Symbol}` kwarg kept (43-PATTERNS requires PVBattery parity;
  `:cyclic` pins `soc[T+1] ≥ soc0` vs the SAME Parameter). It is orthogonal to the soft target at
  `t_dep + 1 ≤ T + 1`.
- EV is active-only: no `q_inject`, `is_flexible_load` stays default false (A1). p_inject =
  `p_dch − p_ch` (V1G: `−p_ch`).
- Certificate placement: NEW file `src/models/complementarity_ev.jl` (peer of
  complementarity_4q.jl), selection trait-routed via the type-paired stash
  (`storage_kind === :ev`), scale-free test `value(p_ch[t])·value(p_dch[t]) < τ_ev·Pmax²` with
  Pmax recovered from the variable's upper bound (the welfare_solve.jl:369-370 idiom),
  `on_violation = :error/:warn` + `CertificateError(; kind = :ev)`, plus a `report = true`
  neutralizer returning the worst ratio (the 4Q contract — the honesty-policy vehicle for the
  negative-price fixture). τ_ev is MEASURED in Task 2 on the committed fixtures (noise floor of
  compliant solves across the 5 two-bus seeds, V1G and V2G), documented in a provenance header
  table in the file — never copied from the battery τ or the 4Q rtol/atol.
- solve_welfare wiring: call `assert_ev_complementarity!` right after

  problem-class-aware `on_violation` convention as the battery call site; the selection loop

- AgrOpt wiring: `check_ev::Bool`/`τ_ev` kwargs mirroring `check_battery` (mid-loop false, final
