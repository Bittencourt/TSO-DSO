```julia
model_sd = BilevelModel(Ipopt.Optimizer, mode = BilevelJuMP.StrongDualityMode())

optimize!(model_sd)

@assert isapprox(value(y_inv, model_bigm), value(y_inv, model_sd); rtol = 1e-4)
@assert isapprox(objective_value(model_bigm), objective_value(model_sd); rtol = 1e-4)
```
`BilevelModel`'s `solver` argument requires a BARE zero-arg constructor (`HiGHS.Optimizer`,
`Ipopt.Optimizer`) — NOT `TSODSO.select_optimizer(...)` (which returns an
`OptimizerWithAttributes`). This is the ONE sanctioned INFRA-02 exception in the whole test suite
(mirrors `ext/TSODSOGurobiExt.jl`'s status as the one sanctioned place a commercial solver is
named) — write this into the file's header comment explicitly.

From 11-01-PLAN.md `<toy_fixture>` (the SAME numeric instance certified here):
`T=1`, `corridor_cap=2.0`, `x_inv_max=2.0`, `c_inv=1.0`, `c_op=[0.5]`, `c_y=0.3`,
oracle welfare closed form `welfare(z) = 2*z - 0.5*z^2` (derived from
`ToyDeviceFixture.ToyElasticDevice(2, 6.0, 1.0, 10.0)` + `λ₀=[4.0]` on
`Phase6Fixtures.two_bus_feeder()` — the closed form, NOT the JuMP oracle itself, is what the
BilevelJuMP Upper() objective embeds directly, since the oracle's own welfare optimization is not
itself a second strategic Stackelberg follower in this reduction — see the "Design note" below).
Hand-enumerated optimum: `y*=1.0, z*=1.0, x_inv*=0.5`, oracle welfare=`1.5`, follower
cost=`1.0`, total leader objective=`-0.2`.

From 11-02-PLAN.md (the production Benders entry point to cross-check against):
```julia
result = solve_stackelberg!(feeder, LinDistFlow(), [agg]; λ₀ = [4.0], T = 1,
    follower_kwargs = (; corridor_cap = 2.0, x_inv_max = 2.0, c_inv = 1.0, c_op = [0.5]),
    master_kwargs = (; c_y = 0.3, y_max = 8.0, α_op_lb = -5.0, α_x_lb = 0.0),
    tol = 1e-6, max_iter = 100, checkpoint_dir = <hermetic tempdir>)
# result.y, result.z, result.UB, result.LB, result.gap
```

**Design note (why only ONE `Lower()` block):** this Stackelberg game has exactly one genuine
strategic follower — the transmission-reinforcement investor (`FollowerLP`). The operational
welfare oracle is a DETERMINISTIC, closed-form function of `z` on this fixture (a lossless 2-bus
network with one load device), not itself a second competing optimizing agent — so it is embedded
directly in the `Upper()` objective as `-(2*z - 0.5*z^2)`, not as a second `Lower()` block.
BilevelJuMP models single-follower bilevel programs; this matches that structure exactly.
