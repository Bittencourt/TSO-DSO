## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Benders loop (future, Phase 11) -> `solve_planning_oracle!` | A caller-provided `z_trial` is an in-process `Vector{Float64}`, no external/untrusted input; a wrong-length or non-finite trial must fail loudly, never silently misindex or propagate a NaN price |
| pinned solve -> returned coupling dual `π` | The dual is the entire product of this oracle (prices ARE duals); a dual read from a non-STRICT solve would be physically meaningless and must never be returned |

Web/network/injection/auth threats are explicitly out of scope (single-process, in-process
Julia numerical-optimization library, no network surface, per project security note).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
