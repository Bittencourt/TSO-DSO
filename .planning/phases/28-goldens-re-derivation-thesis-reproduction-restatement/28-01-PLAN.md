  <action>
    Write a Python 3 (stdlib only, no pip install — `re`, `subprocess`, `argparse`) script,
    `audit_goldens.py`, that: (1) runs `git diff &lt;base&gt;..&lt;head&gt; -- test/` (default base
    `5939799`, default head `HEAD`, both overridable via `--base`/`--head` CLI flags); (2) parses
    the diff into hunks and extracts paired `-`/`+` lines; (3) flags a numeric literal via the
    regex `-?\d+\.\d{3,}` (>=3 decimal digits) OR scientific notation `-?\d+\.?\d*e[+-]?\d+` OR a
    bare integer assigned to a name containing `GOLDEN`/`ATOL`/`RTOL`/`TOL`/`SEED`/`ITER`/
    `MAXITER`; (4) for each flagged pair, scans a +/-5 line window (both removed and added hunk
    context) for an attribution signal: the literal substrings `OLD` and (`-&gt;` or `→`) and
    `NEW`, OR a `Plan-`/`Plan `/`FIX-`/`PM-`/`WR-`/`D-` reference, OR the words "moved"/
    "re-derived"/"re-pin"; (5) restricts extraction to lines that are NOT pure `#`-comment-only
    changes where the number appears only inside prose describing a ratio (i.e. skip lines where
    the number is not assigned to a `const`/passed to `@test`/`isapprox`/`atol=`/`rtol=`); (6)
    normalizes whitespace before comparing extracted numeric strings (not before extracting them)
    to avoid JuliaFormatter-reflow false positives; (7) emits one row per flagged-but-unattributed
    literal (file:line, old value, new value, surrounding comment or "NONE FOUND") to stdout as a
    markdown table, and exits 1 if any unattributed row exists, 0 otherwise. Add a `--selftest`
    mode (no git access) that runs the parser against two embedded synthetic diff-hunk fixtures
    (as Python string literals, mirroring `test_pricing_fit.jl`'s real
    `# Phase 26 gap-closure re-pin (PM-06) — ... OLD &lt;value&gt; -&gt; NEW &lt;value&gt;.` idiom):
    one hunk WITH an attribution comment (must NOT flag) and one WITHOUT (MUST flag); print
    `SELFTEST: PASS` and exit 0 only if both assertions hold, else print `SELFTEST: FAIL &lt;reason&gt;`
    and exit 1.
  </action>
  <acceptance_criteria>
    `audit_goldens.py` exists, is executable via `python3`, requires no pip installs, and its
    `--selftest` mode deterministically prints `SELFTEST: PASS` and exits 0 — proving the detector
    both flags an unattributed synthetic move and does not flag an attributed one.
  </acceptance_criteria>
