Algorithm (RESEARCH.md "The Angle-Recoverability Certificate" section + "Code Examples"
skeleton -- exact mechanism, empirically verified in the research session's own live spike):
for each chord branch `b` with stored endpoints `(from, to)` and impedance `z = r + jx`, using
the chord's OWN solved `(P_b, Q_b)` (never traversal-sign-flipped -- this evaluates the
branch's own defining equation, not a traversal): `V_to,predicted = V_from,tree -
z*conj(S_b)/conj(V_from,tree)` where `S_b = Complex(value(pv.P[b,t]), value(pv.Q[b,t]))` and
`V_from,tree` is the phasor the tree-BFS already assigned to the chord's `from` bus (both
chord endpoints are on the tree, since the whole graph is connected). Compare to `V_to,tree`
(the tree-BFS value already assigned to the chord's `to` bus): `residual =
abs(V_to,predicted - V_to,tree)`. `worst = maximum(residual over every chord, every t)`.
`scale = maximum(abs, Vphasor)` (a magnitude reference over ALL bus phasors, all `t`).
`recoverable = worst <= atol + rtol*scale` (the SAME `atol + rtol*scale` combined-bound SHAPE
every certificate in this codebase uses -- WR-01 -- copied for STYLE consistency only; VALUES
are measured fresh on `Phase23Fixtures`, D-08).

Reads `ctx.meta[:feeder]`, `ctx.meta[:T]`, `ctx.meta[:pf_vars]` (the `(; v, v-hat, P, Q, l)`
stash `ConvexBranchFlow.contribute!` populates -- `MeshedFlow` delegates to it verbatim, plan
23-02) -- identical inputs to `recover_voltage_angles`.
