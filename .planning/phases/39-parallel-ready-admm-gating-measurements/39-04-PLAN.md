## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| equality assertions → executor trust | A tolerance-based "equality" would launder a genuine parallel difference (the exact thing the golden policy forbids) |
| tests → process-global BLAS state | Unrestored BLAS counts poison every later test item in the same process, including the knife-edge canary |
| CI / default suite → thread-gated items | A weakened guard or hidden skip record would fake green under 1 thread |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-04-01 | Repudiation | false equality claim | mitigate | literal == on Float64 traces/welfare/prices (isapprox forbidden by the golden policy); isequal only for the NaN-bearing exact_maxgap; loud @info of measured values before assertions |
| T-39-04-02 | Tampering | BLAS global state leakage | mitigate | save/restore in finally inside the test items; canary re-run in the same process after the parallel items is part of the task's automated verify |
| T-39-04-03 | Repudiation | hidden skips under 1-thread CI | mitigate | skips are loud (@test_skip with the exact run instruction in the message) and every skip record is allowlisted by exact key in expected_broken.txt — an unlisted skip FAILS the run |
| T-39-04-04 | Tampering | wrapped errors hiding attribution | mitigate | poisoned-task leg asserts the threaded error is not TaskFailedException/CompositeException and matches serial type+msg |
| T-39-04-05 | Denial of Service | parallel item cost in CI | accept | threaded items are one extra fixture solve at JULIA_NUM_THREADS=4 (~canary cost); invoked via targeted TSODSO_TEST_FILES, not added to per-commit loops |
