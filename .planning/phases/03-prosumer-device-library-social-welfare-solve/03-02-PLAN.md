<objective>
Deliver the seeded first-order Markov-chain profile generator (DATA-04): a pure, JuMP-free data-layer module that turns a transition matrix + seed into reproducible inelastic-demand and PV hourly profiles. Reproducibility is the whole point — the same seed must produce identical profiles across Julia versions, which is why the RNG is an explicit `StableRNGs` instance threaded through, never the global RNG.

## Phase Goal (user story)

**As a** power-systems researcher, **I want to** generate seeded demand and PV profiles that regenerate bit-for-bit, **so that** the multi-device welfare solve consumes trustworthy, reproducible inputs.

Purpose: Provide the parameter profiles the aggregator/welfare solve consumes, with cross-version reproducibility (INFRA-04).
Output: `src/data/profiles.jl` (Markov generator) + green `profile` tests.
</objective>

  markov_path(P::AbstractMatrix, s0::Int, steps::Int, rng::Random.AbstractRNG) -> Vector{Int}
      # first-order Markov walk; P[s,:] row-stochastic; categorical draw via rand(rng)
  generate_profiles(...; seed::Integer, T::Int=24) -> NamedTuple
      # builds inelastic-demand + PV hourly profiles from state paths; seeds StableRNGs.LehmerRNG(seed)

Reproducibility contract (INFRA-04): two calls with the SAME seed return `==` vectors.
Anti-pattern (RESEARCH §Anti-Patterns): NEVER use Random.seed! / a global RNG — thread an explicit
  StableRNGs.LehmerRNG instance. stdlib Random is NOT stable across Julia minor versions.
