Aggregatable-device contract (implemented in plans 03-03/03-04) the Aggregator consumes:
  contribute!(d::AbstractDevice, ctx; T) -> (; vars, p_inject::Vector, utility::QuadExpr)

Aggregator (this plan):
  struct Aggregator  { bus::Int; φ::Real; devices::Vector{<:AbstractDevice}; Pdc::Vector }
  contribute!(agg::Aggregator, ctx::ModelContext; T::Int) ->
    tanφ = sqrt(1 - φ^2)/φ                                  # reactive relation 3.23
    for each device d: res = contribute!(d, ctx; T); accumulate res.p_inject, res.utility; stash res.vars
    for t in 1:T:
      add_to_residual!(ctx, :Rp, agg.bus, t, Σ p_inject[t] - Pdc[t])     # net active inject (3.22); inelastic demand negative
      add_to_residual!(ctx, :Rq, agg.bus, t, -Pdc[t]*tanφ)              # net reactive from power factor (3.23); DERs active-only (A3)
    add_to_objective!(ctx, Σ device utility)                            # Σ U (3.21)
    stash aggregated device vars under ctx.meta[:agg_device_vars] for the battery check

From src/models/linear_solve.jl (the template to generalize — READ the WR-03 note in full):
  solve_linear(feeder, pf, devices; T, λ₀) -> (ctx, objective, dadp)
