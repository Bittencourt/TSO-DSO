<!-- The exact LL cut algebra (RESEARCH.md Priority Finding 1, cited: Laporte & Louveaux 1993 /
     Birge & Louveaux 2011 Sec 5.2) -- reuse VERBATIM, do not re-derive. -->

Given a trial `b^ν in {0,1}^K` and its EXACT recourse value `Q_nu = Q(b^ν)` (already computed by
the caller as `follower_res.cost - oracle_res.cost` — the SAME quantity `cost_k` minus the
leader's own `c_y*y` term, per `benders.jl`'s existing formula, no new derivation needed here),
and `L` (the master's own stored `master.L = α_op_lb + α_x_lb`, confirmed valid over
`[0, y_max]` by plan 24-01's Task 2 test):

```
S = { i : round(b^ν[i]) == 1 }
D(b) = Σ_{i∈S} b[i] − Σ_{i∉S} b[i] − |S| + 1
θ = master.α_op + master.α_x
cut:  θ >= (Q_nu − L) * D(b) + L
```

Verify-by-construction properties this plan's own tests must prove, exhaustively over all
`2^K = 16` corners on the K=4 fixture (RESEARCH.md's own derivation, reproduced here for the
task author, not to be taken on faith):
  - At `b = b^ν`: `D = 1`, cut reduces to `θ >= Q_nu` — TIGHT.
  - At any OTHER corner (Hamming distance `k >= 1` from `b^ν`): `D = 1 - 2k <= -1`, cut reduces
    to `θ >= L - 2k*(Q_nu - L) <= L` — IMPLIED by the master's own existing `α_op>=α_op_lb`/
    `α_x>=α_x_lb` bound (`θ >= L` always holds structurally), i.e. the cut adds ZERO new
    information at any other corner. This is exactly what "a valid cut must never cut off the
    true optimal lattice point" (D-15) reduces to at the algebra level, and what this plan's own
    unit test proves directly (not deferred to the full certification in plan 24-05).

The classical un-weighted no-good cut (D-16's fallback, same `S` convention, no `Q_nu`/`L`):

```
Σ_{i∈S} (1 - b[i]) + Σ_{i∉S} b[i] >= 1
```

`BendersTrace`'s current `push!` signature (`src/planning/trace.jl`, read this session):

```julia
function Base.push!(trace::BendersTrace, k::Integer; LB::Real, UB::Real, gap::Real,
                     cut_type::Symbol, n_cuts::Integer, master_status::Symbol,
                     oracle_status::Symbol = :not_solved, retry_count::Integer, solve_time::Real)
```

Every field is a parallel `Vector`; `BendersTrace()` constructs all of them empty.
`trace_summary(trace)` returns `(; iters, final_LB, final_UB, final_gap, max_cuts, total_retries)`.

      `(; kind = :ll, b_trial = round.(Int, b_trial), Q_nu, L)` to `master.cuts`, returns `master`.
    - `add_nogood_cut!(master::BendersMasterInteger, b_trial::AbstractVector{<:Real})`: appends

      `(; kind = :nogood, b_trial = round.(Int, b_trial))`, returns `master`.

      (the field `solve_master!(::BendersMasterInteger)` already returns, per plan 24-01), ALWAYS
      calls `add_ll_cut!(master, b_trial, Q_nu, master.L)` (Finding 2: continuous+LL cuts coexist,

      `push!(master.visited, key)`, and IF `stalled` ALSO calls `add_nogood_cut!(master, b_trial)`
      (D-16's anti-stall fallback — fires only on a detected repeat, not every iteration). Returns
      `(; nogood_fired = stalled)`.
