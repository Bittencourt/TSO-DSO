## Phase Goal

**As a** power-systems researcher, **I want to** express a linear distribution-network formulation and a flexible load that meet only at a shared nodal residual and solve them centrally, **so that** I obtain the first nodal-balance dual (the distribution price) and can swap DC↔LinDistFlow without touching device or assembly code.

> Note: the ROADMAP Phase 2 `**Goal:**` line is prose, not user-story form. The story above is a faithful reformatting of that goal (role = researcher per REQUIREMENTS.md; capability + outcome verbatim from the goal). No scope was invented.

<objective>
Extend the Phase-1 `ModelContext` seam so it can carry a real multi-bus feeder and a concave-quadratic welfare objective, and scaffold the Phase-2 include graph so the wave-2/3 plans can fill disjoint files in parallel without ever editing `src/TSODSO.jl` again.

Two capabilities are added to `ModelContext`, both additive (Phase-1 scalar API preserved): (1) an **indexed** `add_to_residual!(ctx, name, i, t, expr)` that lazily allocates/grows a `Matrix{AffExpr}` (the per-bus/per-time nodal residual — the physical balance is affine and MUST stay affine), and (2) `add_to_objective!(ctx, expr)` accumulating a `QuadExpr` under `ctx.meta[:objective]` (the concave utility is NOT affine and must NOT flow through `add_to_residual!`, which converts to `AffExpr` and drops curvature). Per RESEARCH Pattern 4.

Purpose: this is the single coupling seam every downstream phase (3–7) reuses; getting the affine-residual / quadratic-objective separation right here is load-bearing.
Output: extended `ModelContext.jl`, an updated `AbstractPowerFlow` contract docstring, five comment-only source stubs, wired includes, and a green context test.
</objective>
