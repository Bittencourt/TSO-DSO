## Phase Goal

**As a** power-systems researcher, **I want to** express a linear distribution-network formulation and a flexible load that meet only at a shared nodal residual and solve them centrally, **so that** I obtain the first nodal-balance dual (the distribution price) and can swap DC↔LinDistFlow without touching device or assembly code.

<objective>
Fill the two power-flow stubs with concrete `AbstractPowerFlow` subtypes selected by dispatch — `DCPowerFlow` (active-power-only linearization) and `LinDistFlow` (loss-less branch flow with squared-voltage-magnitude variables and the linearized voltage-drop). Each implements `contribute!(pf, ctx, feeder; T)` that *subtracts* net branch terms (inflow − outflow) into the shared per-bus/time residual, and nothing else touches the coupling seam. This is PF-02 and the substance of success criteria 1 and 4.

Purpose: prove the residual seam carries a real multi-bus network model with zero `if formulation ==` branching, so the wave-3 assembly is formulation-agnostic.
Output: `DCPowerFlow.jl`, `LinDistFlow.jl`, and `test/test_powerflow.jl`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| feeder magnitude pu data → squared-voltage model | vmin/vmax are magnitude pu; the model needs their squares — a boundary where a unit slip silently shifts every voltage |
| formulation type → shared residual | The formulation is the only writer of network terms; a stray `if formulation ==` here would break swappability for the whole framework |
