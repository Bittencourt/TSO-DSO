`assert_socp_exact!`'s formula, NEVER delegated to the throwing `assert_socp_exact!` itself, and

```
lhs = value(pv.l[b,τ]) * value(pv.v[br.from,τ]); rhs = value(pv.P[b,τ])^2 + value(pv.Q[b,τ])^2
gap = abs(lhs - rhs); tol = atol + rtol*max(abs(lhs),abs(rhs)); ratio = gap/tol
step_certified = maximum(ratio over all b,τ) <= 1     # NEVER errors here
```
