<objective>
Vendor the two public OpenDSS IEEE-123 source files under a committable path and write a
dependency-free Julia script that regex-parses them and reduces each referenced 3-phase
line-code matrix to a positive-sequence R1/X1 pair via Fortescue-averaging, self-verifying
against a pinned sanity value. This is the offline, reproducible foundation IMPED-01 requires —
PMD stays entirely out of `Project.toml` because no PMD is used at all.

Purpose: give the framework a citable, reproducible provenance chain from public IEEE-123 data
to real per-segment impedances, without introducing any new runtime dependency.
Output: `scripts/data/IEEE123Master.dss`, `scripts/data/IEEELineCodes.DSS` (vendored, provenance-
commented), `scripts/reduce_ieee123_impedances.jl` (parser + reducer + `--verify` self-check).
</objective>
