<objective>
Vendor the public IEEE-8500 OpenDSS source at a pinned commit SHA, and write the dependency-free
reduction script that parses it (MV lines, LV triplex, service transformers, regulators,
capacitors, real per-load kW) into a committed Julia impedance/load table — mirroring
`scripts/reduce_ieee123_impedances.jl`'s pattern exactly, but handling two pitfalls IEEE-123 never
had: phase-suffix-collapse parallel edges, and the corrected 3-winding center-tap transformer
reduction (D-05 REVISED: `R_total = ΣRs[1:3]`, `X_total = 0.5·(Xhl+Xht+Xlt)`).

Purpose: SCALE-01's committed, provenance-tracked fixture starts here — no downstream fixture code
can be written until this table exists and is self-consistent.
Output: 10 vendored `.dss` files at a pinned commit SHA, `scripts/reduce_ieee8500_impedances.jl`,
and the generated `src/data/ieee8500_impedances.jl`.
</objective>
