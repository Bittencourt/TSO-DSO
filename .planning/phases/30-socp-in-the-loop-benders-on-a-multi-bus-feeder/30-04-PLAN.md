`:auto` epigraph-bound derivation (plan 30-02), closing out BILEV-04 and BILEV-05's integration:

1. **`inexact_policy` dispatch (BILEV-04b):** when `solve_planning_oracle!` throws from its

   throw — both must still propagate/route elsewhere unchanged), dispatch on
   `:strict`/`:reject`/`:certify_incumbent`.
2. **Oracle-feasibility-cut branch (BILEV-04a):** when `solve_planning_oracle!` throws from a
   GENUINE `MOI.INFEASIBLE` (the exactness gate never ran), call the new feasibility oracle and
   append its cut — the loop recovers instead of crashing.
3. **Unconditional `bounds_ctx` wiring (BILEV-05):** ALWAYS thread a `bounds_ctx` into
   `build_master` (not only when `:auto` is requested — checker BLOCKER 1), so every
   explicit bound reaching `build_master` through `solve_stackelberg!` is validated at
   build time too, plus a universal runtime floor guard.
4. **AC-recheck-at-convergence (BILEV-04b):** once, at the converged incumbent, never per
   iteration.

lands in one coherent pass because they share the same oracle-throw interception point and the
same convergence-return site.
