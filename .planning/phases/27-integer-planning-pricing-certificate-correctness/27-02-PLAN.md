<objective>
Give `assert_socp_exact!` (src/models/exactness.jl) a per-branch relative exactness floor per
FIX-08: `atol_b = ε * ref_b`, where `ref_b = br.smax^2` for a thermally-limited branch and the
head-branch flow magnitude squared (`P_head^2 + Q_head^2`) for an interior (`SMAX_NO_LIMIT`)
branch — replacing today's flat `atol = 1e-6` applied identically to every branch regardless of
its physical scale. `ε` is a NEW, MEASURED (not guessed) named constant, calibrated so a
deliberately slack cone on a small/interior branch is correctly flagged while every genuinely
exact canonical fixture still passes.

Purpose: today's flat `atol=1e-6` was calibrated against head-branch-scale fixtures; a
lightly-loaded branch (small `smax`, e.g. a fine-grained lateral) can carry a slack cone that is
LARGE relative to its own thermal scale yet still pass, silently returning a physically
meaningless price on that branch's local DLMP contribution. This is the correctness gate's own
scale-blind spot (`assert_socp_exact!` is PF-04, the project's headline correctness gate).
Output: a per-branch exactness gate; a measured `ε`; a synthetic regression proving the new
floor catches what the old one missed; every existing genuinely-exact fixture re-verified (any
newly-flagged fixture escalated as a documented FINDING, never silently accepted).
</objective>

            lhs = value(pv.l[b, t]) * value(pv.v[br.from, t])

    end
