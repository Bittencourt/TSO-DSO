<objective>
Make `corner_recourse` (src/planning/benders.jl) correct for T > 1 per FIX-06: replace the
scalar `fill(z, T)` surrogate with a genuine joint T-dimensional convex minimization
`Q(y_inv) = min_{z in [0,y_inv]^T} [follower_cost(z) - oracle_welfare(z)]`, implemented as a
nested Kelley's-method cutting-plane ("bundle") loop that reuses the EXISTING
`solve_follower!`/`solve_planning_oracle!` production entry points and their already-exposed
duals (`fr.π_s`, `orr.π`) as a first-order oracle — no new solver dependency, no new subsystem.
`T == 1` keeps calling the pre-existing ternary-search code path completely unchanged (byte-
identical output). Validate the new T>1 path against a NEW exhaustive grid-enumeration oracle on
a small T=2 fixture (mirrors `enumerate_lattice`'s existing pattern), matching within a measured
(not guessed) tolerance.

Purpose: `add_ll_cut!`'s Laporte-Louveaux cut requires the TRUE per-corner recourse
`Q(b^nu)`; pinning a single scalar trial across all T hours silently gives the WRONG answer
whenever the oracle's welfare value function is not separable across hours (any aggregator
with a PVBattery/FourQuadBESS/Deferrable member couples `soc[t+1]`/energy-budget windows across
hours) — a correctness gap that blocks Phase 30/31's multi-bus, T>1 Benders planning.
Output: `corner_recourse` correct and validated for T>1; T=1 behavior unchanged; a reusable
T=2 grid-enumeration validation oracle in the test tree.
</objective>
