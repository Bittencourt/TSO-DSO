<objective>
Complete the harness with the storage + sweep layer: `run_and_store(s)` `@tagsave`s a per-run artifact to
a GITIGNORED JLD2 stamped with the git commit (+ dirty patch), Julia `VERSION`, and the seed (INFRA-04
provenance — the committed Manifest is the environment pin, NOT tagsave); `run_sweep(params)` expands a
`dict_list` over scenario parameters, runs each, and `collate_summary` turns `collect_results` into a
deterministically-sorted, fixed-column, `:path`-free, diff-friendly CSV summary committed under
`results/sweeps/` (EXP-02). Two `@quickactivate` scripts give a researcher runnable entry points.

Purpose: EXP-02 (sweeps + flat/versioned/diff-friendly storage) and the provenance half of INFRA-04
(inputs/config/environment/seed recorded per run). The two-tier storage split (gitignored binary JLD2 +
committed text CSV) is the RESEARCH Pattern 3 prescription; diff-friendliness requires all three rules
(fixed column order, deterministic sort, drop :path).
Output: store.jl + sweep.jl + the two scripts; the EXP-02 sweep/diff-friendly and INFRA-04 provenance
testitems green.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| run → persisted artifact | Provenance (commit + VERSION + seed) must be recorded so a run is reproducible. |
| runs dir → committed summary | The committed CSV must be deterministic (no churn) and free of machine-local paths. |
| JLD2 load | Only self-produced artifacts from the project's own data/sims are loaded. |

Verified the saved dict carries gitcommit+julia_version+seed. |
| T-08-11 | Tampering | non-deterministic summary CSV (unsorted / :path column → git churn) | mitigate | All three diff-friendly rules enforced: explicit fixed column select, deterministic sort! by scenario keys, drop the absolute :path column; verified byte-identical across two collations (Pitfall 3). |
| T-08-12 | Tampering | committing binary JLD2 artifacts | mitigate | data/ gitignored (08-01); only the sorted scalar CSV under results/ is committed (two-tier storage). |
