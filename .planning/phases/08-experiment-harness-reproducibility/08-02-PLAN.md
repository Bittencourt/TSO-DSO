<objective>
Deliver the load-bearing design decision of the whole phase: an immutable `Scenario` struct whose fields
are PRIMITIVE selectors (`Symbol`/`Int`/`Float64`/`Bool`/`String`) — so `savename`, hashing, diffing and
reproducibility all fall out for free — plus the `materialize.jl` helpers (`sub_seed`, `build_feeder`,
`build_price`, `build_population`) that deterministically construct the heavy Phase 1–7 objects (feeder,
λ₀, aggregators) from those selectors + a master seed. Validation throws on unknown selectors so a
Scenario always fully determines its run.

Purpose: EXP-01's declarative spec and INFRA-04's reproducibility both hinge on selectors-not-objects
(RESEARCH Summary / Pitfall 1) and on threading independent StableRNGs sub-seeds (Pitfall 5). This plan
owns Scenario.jl + materialize.jl only (file-disjoint from run.jl); it is serialized BEFORE run_scenario
(08-03) because run_scenario consumes the Scenario type and these materializers.
Output: `struct Scenario` (savename-able, validated) and the deterministic materialization layer.
</objective>
