## Resolved design freedoms (documented in-plan per the phase's open-questions mandate)

- **A1 (devices in `:flat`/`:tou` legs):** the price-taker builder contributes ALL devices verbatim via `contribute!` (batteries INCLUDED) — the rebound metric explicitly requires battery-driven shifts. The asymmetry vs `fit_baseline`'s batteryless A4 is a documented comparison property (stated in docstrings; echoed in the 41-04 CSV/writeup). NOT a v1/simplification — the full-asset counterfactual IS the deliverable.
- **A2 (revenue-neutral weights):** weights `w[j,t]` = the DADP run's OWN signed net quantities (`SettlementInput.bus_nets[j][t]`). Rationale: the locked fairness condition is on total PAYMENTS, which settle on net injections; a weighted mean over the same quantities makes the identity algebraic. Documented in the module docstring.
- **A4 (TOU bins):** pinned module constants over the 24-h profile — `_TOU_OFFPEAK_HOURS = 1:6` (00:00–05:59), `_TOU_SHOULDER_HOURS = vcat(7:16, 23:24)`, `_TOU_PEAK_HOURS = 17:22` (16:00–21:59); a 6/12/6 split matching the mem-price shape (overnight trough / shoulder / evening peak). `default_tou_bins(T)` returns them for T == 24 and throws ArgumentError otherwise (caller passes explicit `bins::Vector{Vector{Int}}`).
- **"on_violation = :report" for battery certificates:** `assert_battery_complementarity!` supports only `(:error, :warn)` (verified `src/models/welfare_solve.jl:358`). The price-taker builder implements report semantics by calling with `on_violation = :error` inside try/catch, catching `CertificateError`, and recording `battery_certificate = :refused` + the message on the result. τ stays at the ADMM-consolidation discipline `τ_batt = 1e-3` — never loosened, never dropped (Pitfall 1).
- **Reconciliation tolerance (A3/Pitfall 5):** measured first on the test fixture, then pinned gate-then-golden (10 × measured, floored at 1e-9; measured value cited in a comment at the pin site). Conservation NEVER depends on the split.
- **AC feasibility wrapper signature:** `ac_feasibility_status(feeder, aggs, nets; T)` with `nets[k]` the per-hour net injection aligned with `aggs[k]` (mirrors `_fit_opt_solve`'s per-agg rows); reactive draw per aggregator = `−agg.Pdc[t]·tan(acos(agg.φ))` at `agg.bus` (SITE-2 verbatim). Deliberately UN SHARED from fit.jl's copies (fit.jl:741-744 rationale).

- Solver abstraction: `Model(select_optimizer(QP()))` for QP legs; `Model(select_optimizer(problem_class(ACPowerFlow())))` for AC legs; `assert_solved!(model; dual = false)` before reading values (no duals consumed anywhere in this plan); prices are plain `Float64` vectors — NEVER JuMP `Parameter`s (AgrOpt.jl header).

- Honesty policy: feasibility statuses and certificate refusals are recorded outcomes.
- Structural-vs-solver assertion split: the hand-computed revenue-neutrality anchor asserts `==` (exact representable arithmetic); real-run totals equality asserts a measured pin (different association of the same floats).
- JuliaFormatter 2.10.2 / margin 92 / docstring-hazard rule; fail-loud ArgumentError guards; SEAM headers.
