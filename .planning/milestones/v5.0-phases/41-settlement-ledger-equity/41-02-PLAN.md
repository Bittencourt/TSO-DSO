Metric conventions to implement (41-RESEARCH.md Pattern 5, verbatim intent):
- **Gini**: `G = Σᵢ Σⱼ |xᵢ − xⱼ| / (2 n² μ)` — population form over ALL values including negatives; a relative mean-difference measure that MAY exceed 1; never zero/drop negatives (Raffinetti/De Battisti bias finding).
- **Theil (T)**: `(1/n_pos) Σ (xᵢ/μ_pos) ln(xᵢ/μ_pos)` on the POSITIVE-SUPPORT subset; excluded count reported; non-computable for xᵢ ≤ 0 (log domain) — exclusion-with-disclosure is the literature-standard treatment.
- **Atkinson**: `1 − ( (1/n_pos) Σ xᵢ^(1−ε) )^(1/(1−ε)) / μ_pos` on the positive-support subset; ε = 0.5 fixed module constant (A6 resolution); excluded count reported. This is exactly the CONTEXT-locked treatment.
- **Palma**: `Σ(top decile) / Σ(bottom 40%)` over the ascending-sorted FULL vector (totals cancel — most negative-robust); document the sign caveat when the bottom-40 sum ≤ 0.
- Known-value anchors: uniform vector ⇒ (0, 0, 0, 0.25); hand-computed 4-vector with a negative.
</interfaces>

## Resolved design freedoms (documented in-plan per the phase's open-questions mandate)

- **A6 (Atkinson ε):** module constant `_ATKINSON_EPSILON = 0.5` (common default; any documented choice valid).
- **Palma counts for small n:** `n_top = max(1, floor(0.1n))`, `n_bottom = max(1, floor(0.4n))` — exact 10%/40% shares when n is a multiple of 10 (the known-value anchor uses n = 10).
- **Gini zero/zero-mean degeneracy:** all-equal vector (including all-zero) ⇒ 0.0; `μ == 0` with any `xᵢ ≠ 0` ⇒ ArgumentError (relative mean-difference undefined — documented).
- **Theil/Atkinson all-excluded:** `(index = NaN, n_excluded = n)` — honestly non-computable, reported not thrown.
- **Palma bottom-40 sum == 0:** NaN (undefined, reported); bottom-40 sum < 0: compute the ratio and document the sign caveat in the docstring.
- **Rebound inputs:** NET-LOAD profiles (grid consumption = −net injection) per hour; battery- and deferrable-driven shifts both captured by the same net-load definition (CONTEXT-locked).
- **Rebound ratio with no reductions:** NaN (documented; `isequal`/`isnan` comparisons — the Phase-39 NaN-bearing-key precedent).
