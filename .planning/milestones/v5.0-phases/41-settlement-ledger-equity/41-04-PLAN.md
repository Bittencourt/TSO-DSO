## Resolved design freedoms (documented in-plan)

- **Engine for the heavy artifact:** `:admm` (the thesis-relevant published-price path — `dadp == λ`, Phase-40/42 use ADMM for Case A); the runner ALSO accepts `:centralized`. A non-`:converged` ADMM run fails the runner loudly (41-01 guard) — a budget stop is recorded by the SCRIPT as a status row, never retried into a pass.
- **`A1` asymmetry handling in the artifact:** `:dadp`/`:flat`/`:tou` household equity uses per-house price-taker dispatches (all devices); the `:fit` leg reports equity at BUS (aggregator) granularity because `fit_baseline` is batteryless by design (A4) — the `household_bills.csv` marks the fit leg's rows `granularity = bus` and the writeup states the asymmetry. Never back-fill the fit leg with a different dispatch.
- **Comparison CSV columns** (agent's discretion on exact names per CONTEXT; semantics fixed): tariff, engine, welfare (social), total settlement payments, merchandising_surplus, per-actor totals (DSO/aggregators/wholesale), feasibility_status + n_thermal/n_voltage violations, battery certificate counts (:ok/:refused/:not_checked), gini/theil/atkinson/palma on bills and on surplus, rebound_amount/rebound_ratio (flat and tou vs dadp), provenance (julia_version, threads, blas_threads, seed, t_horizon, mode), status/notes for honest outcomes.
- **Script modes:** `--mode ieee13-ground` (fast smoke: `build_population(:default, ...)` one-aggregator-per-bus on ieee13_modified, T = 24, mem prices) and `--mode case-a-784` (the deliverable: thesis constants T = 24, SEED = 42, profiles seed = sub_seed(42, :profiles), population seed = sub_seed(42, :population), mem prices — exactly scripts/thesis_caseA.jl's constants as restated in the case_a_scaling.jl header).
- **Docs "tiny live slice":** ONE fast `@example` block (2-bus solve_welfare → ledger → flat/TOU → price-taker → feasibility status → the four metrics) — everything heavy reads the committed CSVs (socp_applicability.jl / case_a_population.jl precomputed precedent).

## Binding conventions

- Golden policy: `fit_baseline` / `welfare_accounting` consumed; `optimizer` kwarg passthrough to fit_baseline is the documented tightening seam (Pitfall 2) — NEVER a modification.
- Honesty policy: `CertificateError` / `SolveFailedError` / `ConvergenceError` from any leg → recorded status row with missing certified values (run_solve_outcome idiom); misuse errors propagate nonzero.
- Suite hygiene: any new `@test_broken`/`@test_skip` needs its `expected_broken.txt` line in the same commit (target: none).
- scripts/README.md CI guard: the new script MUST be added to the index table in the same commit that adds the file.
- JuliaFormatter 2.10.x-style config (.JuliaFormatter.toml) / margin 92 / docstring hazard; every new export docstringed (checkdocs = :exports fails the docs build).
