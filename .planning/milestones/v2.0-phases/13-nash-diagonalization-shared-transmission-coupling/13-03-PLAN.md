run_nash!(specs::AbstractVector{<:NamedTuple}, shared::SharedTransmission; z0, tol_outer=1e-4,
  max_sweeps=50, order::Symbol=:forward, ω::Real=1.0, checkpoint_dir) -> NamedTuple with
  fields (; z, x_inv, UB, converged, sweeps, outer_residual, trace, shared, order) on
  convergence; raises ErrorException on max_sweeps exhaustion (never returns a non-converged
  result).

SharedTransmission is a MUTABLE, single-use JuMP model handle: activate_distributor!/
write_back! permanently change its variable bounds/Parameters. Each `run_nash!` call
DESTRUCTIVELY mutates the `shared` instance it is given — a probe matrix that reuses ONE
`shared` object across multiple (seed, order) runs would silently carry state from one run
into the next, corrupting the "independent probe run" premise NASH-04 depends on.

metric — "a simple, auditable... definition, not a statistical summary that could understate
