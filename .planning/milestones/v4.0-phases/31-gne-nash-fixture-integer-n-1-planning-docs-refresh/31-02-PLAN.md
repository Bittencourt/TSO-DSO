`build_master` already has (BILEV-05, Phase 30), and fix the Laporte-Louveaux cut's
unenforced `Q_nu >= L` precondition (`add_ll_cut!`) plus its wrong docstring math — Phase-30
code review WR-02/WR-03's integer-master root cause

`bounds_ctx` option at all — any caller (including this phase's own `run_nash!` integer
wiring, plan 31-04) must supply them unchecked. This plan ports `master.jl`'s EXACT
three-way `bounds_ctx.follower_kwargs` dispatch (`NamedTuple` / `FollowerLP` / `nothing`) and

`derive_alpha_x_lb`/`alpha_x_lb_derivation`/`alpha_lb_margin` from `master.jl` unchanged (no
duplication). `add_ll_cut!` then gains the reviewer's own vetted `Q_nu >= L - atol*max(1,
|L|)` guard, failing loudly instead of appending an invalid cut row.

`benders.jl` calls the EXISTING generic `_accepted_lb_slack(master, label) = 0.0` fallback
regardless of whether this plan has landed yet — this plan only ADDS a new, more specific
method for `BendersMasterInteger`, which Julia's dispatch picks up automatically once both
plans merge; neither plan needs the other to be correct on its own).

  1. Guards: `(α_op_lb === :auto || α_x_lb === :auto) && bounds_ctx === nothing` throws;

     `bounds_ctx !== nothing` -> `alpha_op_lb_derivation(...)`, reject if
     `α_op_lb > d.optimum + alpha_lb_margin(d.optimum, d.gap; floor = rejection_tol)`, else
     `slack_op = slack + abs(d.gap)`; explicit `Real` with `bounds_ctx === nothing` -> pass
     through unvalidated.

     bounds_ctx.follower_kwargs` — `_fk isa NamedTuple` routes to `derive_alpha_x_lb(;
     _fk..., T = T)` / `alpha_x_lb_derivation(; _fk..., T = T)`; `_fk isa FollowerLP` routes
     to the single-argument `derive_alpha_x_lb(_fk)` / `alpha_x_lb_derivation(_fk)`
     dispatch; `_fk === nothing` honestly skips validation (explicit value passes through
     unvalidated; `:auto` in this branch is a hard `ArgumentError`).
  5. Returns a `BendersMaster(..., (; op = Float64(slack_op), x = Float64(slack_x)))`.

function add_ll_cut!(master::BendersMasterInteger, b_trial::AbstractVector{<:Real},
    Q_nu::Real, L::Real)
    length(b_trial) == master.K || throw(ArgumentError(...))
    all(isfinite, b_trial) || throw(ArgumentError(...))
    isfinite(Q_nu) || throw(ArgumentError(...))
    isfinite(L) || throw(ArgumentError(...))
    b_nu = round.(Int, b_trial)
    ...

end
