Each new device implements a method of the shared `contribute!` generic:
  contribute!(d::Device, ctx::ModelContext; T::Int) -> NamedTuple (; vars, p_inject, utility)
    vars     :: NamedTuple of JuMP variable containers (post-solve inspection)
    p_inject :: Vector length T of JuMP expressions — signed ACTIVE injection per hour
                (a consumed load is NEGATIVE, matching the Interruptible sign convention)
    utility  :: QuadExpr — the device's concave-quadratic utility
  The device builds all @variable/@constraint on `ctx.model` but writes NOTHING to
  `ctx.residuals` and calls NO add_to_objective!. The Aggregator (plan 03-05) consumes the
  return tuple and is the sole :Rp/:Rq writer.

                                     promotion outer constructor, and utility sign (a·p − (b/2)p²).
