## Phase Goal

**As a** power-systems researcher, **I want to** express a linear distribution-network formulation and a flexible load that meet only at a shared nodal residual and solve them centrally, **so that** I obtain the first nodal-balance dual (the distribution price) and can swap DC↔LinDistFlow without touching device or assembly code.

<objective>
Assemble the seam into the rung-1 centralized solve — the earliest point a real feeder-based linear model produces the first distribution price. `solve_linear(feeder, pf, devices; T, λ₀)` calls `contribute!` on the formulation and each device, injects a frontier import `p_import` at the root priced at λ₀, closes *every* residual present (`:Rp` always; `:Rq` only when the registry contains it — a data-driven `haskey` test, NOT formulation branching), maximizes welfare `Σ utility − λ₀ᵀ·p_import`, solves the QP via the factory, gates on OPTIMAL via `assert_solved!(dual=true)`, and returns the nodal-balance dual as the DADP.

The happy-path end-to-end test is the analytic 2-bus loss-less LinDistFlow fixture with a closed-form price (`DADP = λ₀`, `p* = (a−λ₀)/b`). The conformance test proves criterion 4: the DC↔LinDistFlow swap changes only the `pf` argument — no edit to the device or to `solve_linear`.

Purpose: deliver the first price signal and lock the swappability contract that every later rung depends on.
Output: `linear_solve.jl`, `test/test_linear_solve.jl`, `test/test_conformance.jl`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| solver result → "trusted price" | Reading dual() of a non-optimal or wrong constraint yields a false price that looks legitimate |
| formulation choice → assembly | If assembly branches on the formulation, swapping it silently changes results or breaks — the whole seam's value collapses |
| model file → solver identity | Naming a concrete solver in the model violates INFRA-02 and hides the factory's accurate-dual choice |

| T-02-01 | Tampering | price sign | mitigate | Frontier import positive / load negative (toy_dc convention); test asserts dadp[1] > 0 and ≈ λ₀ (Pitfall 2) |
