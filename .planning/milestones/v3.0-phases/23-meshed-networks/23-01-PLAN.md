     including the sparse incidence build (`Irow`/`Jcol`/`Vval` -> `sparse(...)`) that
     produces the returned `N x B` matrix.
  5. BFS connectivity from `root` over an undirected adjacency list built from
     `push!(adj[br.from], br.to); push!(adj[br.to], br.from)` -- KEEP verbatim (this is
     ALREADY graph-generic; it does not assume a tree).

     checks).
